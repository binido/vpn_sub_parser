# Разработка и выпуск

## Выпуск релиза

Версия живёт в **трёх файлах**, и поднимать её нужно во всех сразу — иначе в
именах артефактов останется старая:

- [package.json](package.json)
- [src-tauri/tauri.conf.json](src-tauri/tauri.conf.json)
- [src-tauri/Cargo.toml](src-tauri/Cargo.toml)

После правки версии обновить `Cargo.lock` (`cd src-tauri && cargo check`) и:

```bash
git commit -am "chore: release v0.2.0" && git tag v0.2.0 && git push --follow-tags
```

Пуш тега вида `v*` запускает [.github/workflows/release.yml](.github/workflows/release.yml).
Workflow собирает артефакты и складывает их в **черновик** релиза — опубликовать
его нужно руками в разделе Releases. Секреты не нужны, хватает штатного
`GITHUB_TOKEN`, но в настройках репозитория должно стоять
Settings → Actions → General → Workflow permissions → **Read and write**.

| Платформа       | Артефакт                                |
| --------------- | --------------------------------------- |
| Windows x64     | `..._x64-setup.exe` (NSIS)              |
| Windows ARM64   | `..._arm64-setup.exe` (NSIS)            |
| macOS (Apple M) | `..._aarch64.dmg`                       |
| Linux x64       | `..._amd64.AppImage` и `..._amd64.deb`  |

## Подписи

Сборки подписаны ad-hoc (`bundle.macOS.signingIdentity: "-"`), но не заверены у
Apple и Microsoft:

- **macOS** — первый запуск через правый клик по приложению → «Открыть». Если
  система всё равно ругается: `xattr -cr "/Applications/VPN Sub Parser.app"`.
- **Windows** — SmartScreen: «Подробнее» → «Выполнить в любом случае».

Убрать предупреждения полностью можно только платными сертификатами (Apple
Developer ID с нотаризацией, code signing certificate для Windows) — они
подключаются к тому же workflow через переменные окружения Tauri.

Без `signingIdentity: "-"` Tauri подписывает только исполняемый файл, а не
бандл, и macOS считает скачанное приложение повреждённым.

## Особенности сборки

- Фронтенд собирается без бандлера: `withGlobalTauri` отдаёт API плагинов через
  `window.__TAURI__`, поэтому npm-зависимостей во время выполнения нет, а
  `npm install` нужен только ради Tauri CLI.
- В `app.security.csp` обязаны быть `ipc: http://ipc.localhost` в `default-src`
  и `connect-src`, иначе вызовы команд из webview блокируются.
- В `Cargo.toml` включена фича `log` у `zune-jpeg` — обход бага крейта на
  rustc 1.96+, где `warn!` без этой фичи разворачивается в пустоту и ломает
  сборку. Убрать, когда исправят апстрим.
- AppImage весит около 77 МБ против пары мегабайт у остальных: внутрь него
  целиком уезжает WebKitGTK. Это цена формата, а не раздутая сборка — кому
  важен размер, рядом лежит `.deb`, берущий `webkit2gtk-4.1` из системы.

## Поведение парсера

- Профиль-балансировщик (в JSON-подписке — конфиг с десятками outbound'ов,
  например «Авто») схлопывается в первый сервер, как его показывают клиенты.
- Одинаковые серверы не склеиваются: сто профилей на четыре адреса дадут сто
  карточек — ровно то, что увидит VPN-клиент.
- Проверка пинга меряет TCP-подключение к серверу, а не HTTP-запрос через
  прокси. Задержка настоящая, но работоспособность ключа не проверяется. Если
  на машине поднят VPN или локальный прокси, отвечать может он — тогда все
  серверы покажут одинаково низкие числа.
